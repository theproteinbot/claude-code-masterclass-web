90-Minute Workshop Plan (Interactive)

This is a high-density, hands-on entry workshop that introduces safe agentic coding workflows with Claude Code and a short Codex CLI transfer comparison.

TOC Mapping (Required)

  • TOC 1: Setup, session commands, permissions, quick build, Git, MCP preview
  • TOC 2: Clarifying questions, plan mode, context hygiene, reliable package choices
  • TOC 4: Signal-to-noise + progressive disclosure (light intro)
  • TOC 5: Bonus Codex CLI transfer (short compare)

Workshop Outcomes

By minute 90, learners should be able to:

  • Run one plan-first coding task end-to-end with verification and commit. [Source: https://docs.anthropic.com/en/docs/test-and-evaluate/define-success] [Source: https://git-scm.com/docs/git-commit]
  • Explain why permissions/sandboxing matter in agentic workflows. [Source: https://docs.anthropic.com/en/docs/claude-code/security]
  • Use a context-minimizing prompt and identify one context bloat anti-pattern. [Source: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/long-context-tips]
  • Compare Claude Code and Codex CLI at a workflow level (not feature memorization). [Source: https://github.com/openai/codex] [Source: https://platform.openai.com/docs/guides/codex]

Materials Needed

  • Training repo with tests and 1-2 intentional bugs
  • Projector/demo terminal
  • Printed/shared PROMPT_CARDS.md
  • LABS.md Lab 1 + Lab 2 excerpts
  • Git installed for all learners [Source: https://git-scm.com/docs]

Pre-Workshop Setup (15-30 min before learners arrive)

  • Reset training repo to workshop start branch.
  • Confirm CLI login and network access.
  • Open docs tabs for citations and quick reference.
  • Prepare one fallback local transcript if demo fails.

Instructor Script Prompts (Ready to Use)

Demo Prompt 1 (Quick Build)

"Before writing code, propose a 5-step plan. List assumptions, risks, and exactly how you will verify success (tests, commands, files to inspect). Then wait for approval."

Why this works: asks for plan, assumptions, and verification, which aligns with prompt/evaluation best practices. [Source: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview] [Source: https://docs.anthropic.com/en/docs/test-and-evaluate/define-success]

Demo Prompt 2 (Refactor)

"Refactor incrementally. Keep behavior unchanged. After each step, summarize the diff and what regression risk it might introduce. Stop if tests fail."

Why this works: encourages iterative refactoring and verification loops. [Source: https://martinfowler.com/articles/workflowsOfRefactoring.html] [Source: https://docs.anthropic.com/en/docs/test-and-evaluate/develop-tests]

Workshop Troubleshooting (Fast Responses)

  • If installs fail: switch to preconfigured VM/container or follow along on shared screen.
  • If agent output is noisy: force a plan-only step and narrow file scope. [Source: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/long-context-tips]
  • If learners are blocked by Git: use a helper branch and resume lab at next checkpoint. [Source: https://git-scm.com/docs/git-switch]

Assessment Evidence (End of Workshop)

Collect from each learner/team:

  • Prompt used
  • Acceptance criteria list
  • Diff screenshot or patch summary
  • Test/check output
  • Commit hash/message (optional in beginner path)
  • 2-sentence reflection on what improved/worsened output quality
